# ۴۲ افکت ویدیویی برای Claude

ویدیوت رو بنداز توی Claude، بنویس `/effects` و اسم افکت. کل تدوین همینه!

ساخته‌شده توسط [@tarfandhaye.ai](https://instagram.com/tarfandhaye.ai) 💛

## نصب (بدون هیچ کار فنی)

1. فایل zip این اسکیل رو دانلود کن (همونی که برات فرستادم).
2. Claude Code رو باز کن، فایل zip رو بکش بنداز توی چت و این رو بنویس:

**«این فایل یه اسکیل Claude Codeـه. نصبش کن (پوشه‌ی ~/.claude/skills/effects بساز و محتوای zip رو بریز توش، طوری که SKILL.md مستقیم توی همون پوشه باشه). بعد بگو چی کار کنم.»**

3. وقتی Claude گفت نصب شد، Claude Code رو یه بار ببند و باز کن. تموم!

## چطوری استفاده کنم؟

1. Claude Code رو باز کن (اپ یا ترمینال).
2. ویدیوت رو بکش بنداز توی چت.
3. افکتی که می‌خوای رو بنویس:

```
/effects orbit از ثانیه‌ی ۳ تا ۶
/effects spotlight وقتی می‌گم «چراغا رو خاموش کن»، با کلمه‌ی Claudit پشت سرم
/effects comment-box آخر ویدیو، که CLAUDE تایپ کنه
/effects glass-widgets برای ۳ ثانیه‌ی اول
```

بار اول، Claude خودش همه‌چی رو راه می‌ندازه (حدود ۲ دقیقه). به `ffmpeg` و Python نیاز داره و اگه نداشته باشی، خودش برات نصبشون می‌کنه.

Claude اول چندتا فریم رو چک می‌کنه، هر چیزی که روی صورتت افتاده باشه رو درست می‌کنه، بعد فایل `yourvideo_effects.mp4` رو درست کنار ویدیوی اصلیت می‌سازه. صدای ویدیوت هم دست‌نخورده می‌مونه.

می‌تونی چندتا افکت رو یه‌جا روی هم بچینی: *«از ثانیه‌ی ۶ تا ۱۰ locked-on بذار، بعد از ۱۰ تا ۱۳ orbit، بعد هم روی کلمه‌ی "نه" یه reject stamp.»*

همه‌ی افکت‌ها صورتت رو دنبال می‌کنن. هر چیزی که قرار باشه روی صورتت بیفته، می‌ره پشت سرت.

**نکته‌ها**
- ویدیوهای عمودی گوشی که خودت توی کادری، بهترین نتیجه رو می‌دن.
- زمان رو ساده بگو («وقتی می‌گم "ببین"»). Claude خودش ثانیه‌ی دقیقش رو پیدا می‌کنه.
- می‌خوای ریل‌های خودت توی `orbit`، `noise`، `phone-fan` یا `profile-wall` باشن؟ یه پوشه اسکرین‌شات بده به Claude.
- نمودارها، شمارنده‌ها و تیترها بهتره عددهای واقعی خودت باشن. به Claude بگو چین.
- خروجی 1080p ساخته می‌شه. اگه 4K می‌خوای بگو (کندتره).

## حرف راست
- اینا **نسخه‌های اولیه‌ان**. دقیقاً مثل یه تدوین حرفه‌ای درنمیان، چون اون صداگذاری و زمان‌بندی دستی هم داره.
- Claude پیش‌نویس می‌کنه، تو تأیید می‌کنی. قبل از پست کردن نتیجه رو ببین.
- صدا و زیرنویس اضافه نمی‌شه. اونا رو توی CapCut بذار.
- برای ترفندهای بیشتر هوش مصنوعی و تدوین، [@tarfandhaye.ai](https://instagram.com/tarfandhaye.ai) رو توی اینستاگرام فالو کن.

## اگه یه چیزی درست نبود
فقط به Claude بگو چی می‌بینی («کلمه افتاده روی صورتم»، «خیلی تنده»). خودش برنامه رو درست می‌کنه و دوباره رندر می‌گیره.
